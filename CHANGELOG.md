# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

### Added

- pnpm + Turborepo monorepo: `apps/api`, `apps/web`, `packages/shared`, `packages/db`.
- Docker Compose development stack — Postgres 17, Redis 7, MinIO (private bucket), Mailpit.
- Prisma schema for the unified `User` model, sessions, TOTP credentials, courses, enrollments, uploads, resources, announcements, threaded comments, conversations, notifications, and an append-only audit log.
- `scripts/check-brand.ts` — the product name may be spelled in one file; the previous product name in none.
- `scripts/check-mobile-first.ts` — seven desktop-first patterns rejected in `apps/web/src` (ADR 0008).
- `scripts/generate-permissions-doc.ts` — regenerates `docs/permissions.md` from the policy module; `--check` fails CI when the two disagree.
- CI pipeline: typecheck, lint, format, brand check, mobile-first check, unit tests including the policy matrix, integration tests against real Postgres and Redis, build, and the permissions-doc check.
- `contract-drift` workflow — renames a Prisma column on a scratch branch and asserts that `pnpm -r typecheck` **fails**. A passing typecheck fails the job.
- Multi-stage `Dockerfile`: non-root, production dependencies only, the built SPA served single-origin by the API, tini as PID 1, `HEALTHCHECK` on `/readyz`.
- ADRs 0001–0008 in `docs/adr/`.
- `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `NEXT.md`, MIT `LICENSE`.

Everything above is the scaffold. Everything below is the product built on it, in the order it landed.

- **Thirteen API modules**, all registered and serving: departments, courses, enrollments, users, conversations, notifications, dashboard, admin, audit-events, resources, uploads, announcements, comments.
- **Notifications** — one `notify()` writer, ten event types wired (enrolment requested/approved/rejected/withdrawn, resource published, announcement published, message received, comment replied, top-level comment, course published), a paginated archive at `/notifications`, and a bell that reuses the archive's cache path rather than observing twice.
- **Admin CRUD** for users, departments and courses, behind real sub-navigation, with demo-provenance denials rendered as calm copy rather than errors.
- **Ranked search** across courses, resources and announcements — `tsvector` combined with the `pg_trgm` indexes so partial codes (`WELD-2`) still match, with visibility resolved by each module's own `visibilityWhere` and never restated in SQL.
- **Uploads, end to end** — presigned PUT and GET, an avatar picker, syllabus download, a sweeper for abandoned uploads, real byte-level progress via XHR, and immutability after commit (the PUT writes to a `_pending/` staging key that `commit` verifies and server-side-copies onto the final key).
- **Attendance** — `AttendanceRecord` satelliting `Enrollment`, a transactional whole-register `PUT`, and a per-intake register with a student's own summary.
- **Prerequisites** — `Course.prerequisiteCourseId` composed into `enrollment:request`, with cycle prevention that walks the chain.
- **Workshop capacity** — a second guarded number sharing ADR 0006's single conditional `UPDATE`; 200 concurrent approvals against capacity 30 / workshop 5 seat exactly 5.
- **Cohorts** — `Course` became a template and `CourseOffering` an intake; enrolment repointed to the offering, so applying to the next intake creates a new row.
- **Streamed CSV exports** (enrolment register, attendance, audit feed) through a lazy async-generator `Readable` with RFC 4180 quoting — no new dependency, O(batch) memory.
- **MFA enrolment UI** — QR, secret, confirmation code and one-time recovery codes, against the already-proven TOTP backend.
- **Account reinstate** (`POST /users/:id/reinstate`, `user:reinstate`), giving the audit extension's `REINSTATE` derivation its first writer.
- **Threaded comments and announcements**, with comments scoped to their parent's visibility by importing that module's own rule rather than restating it.
- `pnpm screenshots` — 25 captures generated by driving the real app across six role sessions, with a staleness guard that fails the run when a route has no capture. Documented in `SCREENSHOTS.md`.
- **Playwright e2e over the built bundle** at three viewports (desktop, Pixel 7, iPhone 14): a boot smoke test, the dialog accessibility and reduced-motion contracts, and the mobile-first touch-target rule. Wired into CI as the `e2e` job.
- Migrations `0001`–`0008`, all applied from scratch.

### Fixed

- **The production bundle did not run.** `manualChunks` matched `react-dom` as a substring of the absolute module id, and pnpm encodes peer dependencies in its store directory names — so `@tanstack/react-router` was classified by its peers and split across two mutually-importing vendor chunks. The built SPA threw `Cannot read properties of undefined (reading 'createContext')` on every page while typecheck, lint, unit tests, `vite build` and `vite dev` were all green. Chunks are now chosen by package name, and `e2e/build-smoke.spec.ts` loads the artefact in a browser on every push.
- **`Forgot password?` was an 18 px touch target** on `/login`, under ADR 0008's 44×44 floor. The e2e rule that should have caught it exempts inline links by computed `display`, which blockifies for a flex child.

### Changed

- Repository history rewritten in place to remove `node_modules` from every commit: 1,814 tracked files to 305, `.git` from 17 MB to 1.7 MB (ADR 0001).

### Removed

- Nothing yet. `backend/` and `frontend/` remain tracked until the rebuild replaces them.
